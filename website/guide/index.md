# What is Bonsai

Bonsai is a safe, zero-dependency expression language for rules, filters,
templates, and user-authored logic. It runs in Node 24+, Bun, and modern ESM
browsers.

Use it when expressions come from config, admin tooling, product builders, or end
users and still need to run safely in production.
